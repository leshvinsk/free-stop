## Getting Help

Free Stop is maintained by volunteers. Support is provided on a best effort basis through the public channels listed below, so that answers benefit the whole community.

## Before You Ask

Please review the following resources first, as they answer most common questions:

- The [README](README.md), for installation, configuration and local development
- The methodology page of the live site, for an explanation of every score and label
- [Existing issues](https://github.com/leshvinsk/free-stop/issues?q=is%3Aissue) and [discussions](https://github.com/leshvinsk/free-stop/discussions), to see whether the question has already been answered

## Support Channels

| Need | Channel |
|---|---|
| A question about using or developing Free Stop | [Discussions, Q&A category](https://github.com/leshvinsk/free-stop/discussions/categories/q-a) |
| An idea or suggestion that is still taking shape | [Discussions, Ideas category](https://github.com/leshvinsk/free-stop/discussions/categories/ideas) |
| A defect in the site or the code | [Bug report](https://github.com/leshvinsk/free-stop/issues/new/choose) |
| Inaccurate Formula 1 data | [Data correction](https://github.com/leshvinsk/free-stop/issues/new/choose) |
| A concrete feature proposal | [Feature request](https://github.com/leshvinsk/free-stop/issues/new/choose) |
| A security vulnerability | [Private security advisory](https://github.com/leshvinsk/free-stop/security/advisories/new), as described in [SECURITY.md](SECURITY.md) |
| A Code of Conduct concern | **leshvinsk@icloud.com**, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Response Expectations

| Channel | Typical first response |
|---|---|
| Discussions | Within five working days |
| Issues | Within five working days |
| Security reports | Within 72 hours |
| Code of Conduct reports | Within 72 hours |

## What Is Not Supported

- Questions about Formula 1 results or regulations that are unrelated to Free Stop
- Problems with self hosted deployments that have been modified beyond the published configuration
- Requests for private, one to one assistance
